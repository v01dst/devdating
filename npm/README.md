# DevDating

**Swipe. Match. Contribute.** — find open-source projects and beginner-friendly GitHub issues worth solving.

This package is the bootstrap installer for DevDating. It clones the application
from GitHub and provides the `devdating` CLI.

## Install

```bash
npm install -g @v01dst/devdating@latest
devdating install
devdating up
```

Then open:

| Page | URL |
|---|---|
| Discover (swipe) | http://localhost:3000/discover |
| Projects | http://localhost:3000/projects |
| Issues | http://localhost:3000/issues |
| Maintainer Hub | http://localhost:3000/maintainer |
| Profile | http://localhost:3000/profile |

## Update

```bash
devdating upd    # pull latest source, upgrade packages, apply migrations, restart
```
